# 👑 Планёр — королевский личный планер (Android)

Планирование на день, неделю, месяц и год по лучшим методикам:

- **День:** намерение, энергия и настроение · «Съешь лягушку» · правило 1-3-5 · тайм-блокинг · привычки · помодоро · вечерняя рефлексия (благодарности, победы, урок, оценка). Перенос невыполненного на завтра.
- **Неделя:** фокус и девиз · роли и «большие камни» (Кови) · цели недели · обзор 7 дней · трекер привычек · еженедельный обзор GTD.
- **Месяц:** тема месяца · календарь с прогрессом и настроением · цели · важные даты · привычки за месяц · итоги.
- **Год:** слово года и видение · колесо баланса · OKR · 12-недельные кварталы · карта месяцев · «Год в пикселях» · мечты · итоги.
- **Казна (финансы):** бюджет месяца — доходы, распределение бюджета по категориям (автоматически по шаблону процентов, по прошлым тратам или вручную), быстрая запись расходов с автоопределением категории по комментарию, правило 50/30/20, «заплати сначала себе», конверты-лимиты, структура расходов · копилки с расчётом взноса в месяц, подушка безопасности, список желаний по правилу 30 дней · долги методом снежного кома или лавины · календарь обязательных платежей · финансовый обзор года.
- **Ещё:** Входящие (GTD) · матрица Эйзенхауэра · таймер помодоро · привычки · роли · справочник методик · 4 темы оформления · резервная копия.

Данные хранятся только на телефоне.

## Сборка
APK собирается GitHub Actions (`.github/workflows/planner-apk.yml`) при каждом пуше в `planner/` и публикуется в Releases как `Planer.apk`.
Локально: `cd planner && gradle assembleRelease` (нужен Android SDK).
