# Заметки

Приложение-блокнот для Android с доступом по паролю.

**Главное:** приложение всегда спрашивает пароль. У вас три своих блокнота, каждый
со своим паролем. Любой другой пароль тоже открывает блокнот — общий чужой,
с посторонними заметками. Сообщения «неверный пароль» не существует, поэтому по
поведению приложения нельзя понять, что введён не тот пароль. Заметки поддерживают
фотографии.

## Как это работает

Из пароля вычисляется (PBKDF2, 120 000 итераций) пара «ключ шифрования +
имя папки блокнота». Никакой проверки пароля нет — проверять нечего:

* три ваших пароля → три папки, созданные при настройке → три независимых блокнота.
  Заметки одного не видны из другого;
* любой другой пароль даёт имя папки, которой не существует, — и открывается общий
  чужой блокнот. Пустой экран выдал бы, что пароль не подошёл, — его не бывает;
* чужой блокнот **всегда один и тот же**: его заметки выбираются случайно один раз,
  при установке, и дальше не меняются. В нём можно писать и удалять — он ведёт себя
  как настоящий, и правки сохраняются;
* сколько бы разных неверных паролей ни ввели, новых блокнотов не появляется.

Дополнительно при первом запуске создаётся несколько папок-пустышек на случайных
ключах, которые не открываются никаким паролем, — чтобы по количеству папок нельзя
было понять, сколькими паролями реально пользуются.

Заметки и фотографии шифруются AES-256-GCM. Пароли на устройстве не хранятся
ни в каком виде — ни сами, ни их хеши.

## Установка на телефон

Готовый APK собирается автоматически на GitHub Actions — ничего устанавливать
на компьютер не нужно. Скачать последнюю сборку:

**<https://github.com/kartaviyukr/-/releases/tag/apk-latest>** → файл `zametki.apk`

Откройте эту ссылку прямо в браузере телефона, скачайте `zametki.apk` и нажмите
на него. Android спросит разрешение на установку из этого источника (на Samsung:
«Установка неизвестных приложений» → разрешить для браузера) — это обычный вопрос
для приложений не из Play Market. После установки в списке приложений появится
значок «Заметки».

Новая сборка запускается при каждом изменении кода в ветке; её также можно
запустить вручную на вкладке **Actions** в репозитории. Все сборки подписаны одним
ключом, поэтому обновление ставится поверх старой версии и заметки сохраняются.

### Сборка у себя (необязательно)

Нужен Android Studio (Ladybug или новее) либо Android SDK с `ANDROID_HOME`:

```bash
./gradlew assembleRelease
# APK: app/build/outputs/apk/release/app-release.apk
```

## Первый запуск

При первом открытии приложение просит придумать три пароля — по одному на каждый
ваш блокнот. Пароли должны быть разными; нажмите значок глаза и проверьте набранное,
восстановить их потом невозможно. Далее при каждом запуске показывается только одно
поле ввода пароля: какой введёте, тот блокнот и откроется.

Внутри: «+» — новая заметка, долгое нажатие на заметке — удалить, значок замка
в правом верхнем углу — заблокировать. Поле «Поиск» над списком ищет по всем
заметкам блокнота сразу.

Внутри открытой заметки значок лупы включает поиск по ней: все совпадения
подсвечиваются, стрелки ↑ и ↓ внизу переходят между ними, рядом видно «3 из 12».
Ищется любая подстрока — часть слова, отдельные символы, кусок с пробелом;
регистр не важен, «ё» и «е» считаются одной буквой. На время поиска заметка
показывается только для чтения, крестик слева возвращает к правке.

В редакторе заметки кнопки **Галерея** и **Камера** прикрепляют фото. Фотография
уменьшается до 2048 px, сжимается и сохраняется в зашифрованном виде внутри
приложения — в галерею телефона она не попадает. Нажатие на миниатюру открывает
фото на весь экран (масштабирование двумя пальцами), крестик на миниатюре удаляет.

## Что важно знать

* **Пароль восстановить невозможно.** Он нигде не хранится, а заметки без него не
  расшифровать. Забыли пароль — заметки потеряны.
* **Опечатка при вводе выглядит как чужой блокнот.** Это не поломка: введите пароль
  заново, внимательно. Чужой блокнот всегда одинаковый, так что узнать его легко.
* Обновление с версии 1.0 (один блокнот) сохранит ваш старый блокнот, но три новых
  не создаст: чтобы задать три пароля, нужно очистить данные приложения
  (Настройки → Приложения → Заметки → Память → Очистить данные) — старые заметки
  при этом удалятся.
* Приложение блокируется само, как только вы его сворачиваете; ключ стирается из
  памяти. Открытие галереи или камеры блокировку не вызывает.
* Скриншоты и превью в списке недавних приложений запрещены (`FLAG_SECURE`).
* Резервное копирование в облако Samsung/Google отключено намеренно: копия данных
  вне телефона свела бы защиту на нет. Обратная сторона — при сбросе или потере
  телефона заметки не восстановятся, экспорта пока нет.
* Смены пароля пока нет: пароль неотделим от хранилища. Чтобы сменить, придётся
  перенести заметки в новое хранилище вручную.
* Защита рассчитана на человека, который взял телефон в руки. Против криминалистической
  экспертизы с полным образом памяти устройства она не рассчитана.
* Ключ подписи (`signing/app.jks`) лежит в репозитории открыто. Он нужен только для
  того, чтобы обновления ставились поверх старой версии; заметки он не защищает.
  При желании его можно заменить своим и хранить в секретах GitHub.

## Устройство проекта

```
app/src/main/java/com/simple/notes/
├── MainActivity.kt          экраны и автоблокировка
├── AppViewModel.kt          состояние приложения
├── crypto/Crypto.kt         PBKDF2 + AES-256-GCM
├── data/Vault.kt            хранилища: открытие, чтение, запись
├── data/Decoy.kt            наполнение чужих блокнотов
├── data/Note.kt             модель заметки
├── data/NoteSearch.kt       поиск внутри заметки
├── data/ImageUtils.kt       подготовка фотографий
└── ui/                      экраны на Jetpack Compose
```

Данные лежат в приватной папке приложения: `files/v/<хранилище>/n.dat` — заметки,
`files/v/<хранилище>/m/<файл>` — фотографии. Все файлы зашифрованы.
