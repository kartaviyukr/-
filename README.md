# Велоподмосковье — Android-приложение

Велопутешествие по Москве, Подмосковью и старым городам вокруг: 200 мест выстроены в **спираль от Кремля** —
старт в ЦАО, затем 9 административных округов Москвы внутри МКАД, дальше кольцами наружу
(<20, 20–40 … 120–150, 150–200, >200 км) до Твери, Тулы, Рязани, Владимира, Суздаля и Ярославля. Внутри кольца — по часовой стрелке. Каждое место — свой веломаршрут с точками,
рассказом экскурсовода, фактами с источниками, «вкусом места» и званием. Карта области закрыта «туманом»,
который рассеивается по мере прохождения.

## Установка (только Android, iPhone не нужен)

1. На телефоне откройте [**Releases → velopodmoskovye-latest**](../../releases/tag/velopodmoskovye-latest).
2. Скачайте `velopodmoskovye-*.apk`.
3. Откройте файл и разрешите установку из этого источника
   (Samsung: *Настройки → Приложения → Специальный доступ → Установка неизвестных приложений*).

Нужен Android 8.0 (API 26) или новее. APK собирается автоматически при каждом push — GitHub Actions
(`.github/workflows/android.yml`): проверка контента → юнит-тесты → сборка → релиз.

## Что умеет MVP

| Экран | Что есть |
|---|---|
| **Спираль** | все 200 мест строго по порядку от ЦАО наружу, кольца, «следующее по спирали», прогресс, фильтры, сортировка по длине маршрута, расстоянию от меня и от Кремля, числу точек, поиск по местам и точкам маршрутов (найденная точка открывается сразу) |
| **Карта** | MapLibre + OpenFreeMap (без ключа), туман войны с открытыми зонами, маршруты и точки, фильтры по ★/☆ и типу места, моё положение |
| **Место** | вступление, карта маршрута и её загрузка для офлайна, «успеваю до заката?» на выбранную дату, подсказка оптимизатора, кнопки Google Maps блоками по 9 точек (+ пешеходный режим), точки, блюдо, звание, источники |
| **Активный маршрут** | следующая точка и расстояние, рассказ гида с озвучкой (TTS), чек-лист, автоотметка по геофенсу, ручная «Я здесь» с проверкой расстояния |
| **Точка** | рассказ, факты с пометкой «проверено / не проверено» и ссылкой на источник, предупреждения, часы работы |
| **Звания** | анимация выдачи, карточка с легендой и ритуалом, шаринг картинкой, мета-звания (округ, кольцо, все ★, вся спираль), «Самые-самые», статистика |
| **Настройки** | радиус геофенса, средняя скорость, тема, режим «вдвоём», офлайн-карта области, сброс прогресса |

Контент MVP: **Реутов, Котельники, Одинцово, Балашиха**. Кремль, Коломенское, Царицыно, Останкино и другие
места внутри МКАД — точки маршрутов своих округов (ЦАО, ЮАО, СВАО…), а не отдельные пункты спирали.

## Архитектура

```
app/src/main/java/ru/velopodmoskovye/
├── domain/              чистый Kotlin, без Android — покрыт юнит-тестами
│   ├── model/           схема контента (Region, Destination, Stop, Dish, Title…)
│   ├── geo/             расстояния, азимуты, полигоны, выпуклая оболочка
│   ├── spiral/          SpiralBuilder: ЦАО → округа внутри МКАД → кольца наружу, по часовой стрелке
│   ├── route/           GoogleMapsLinks, RouteOptimizer (TSP), RouteTiming, Sun
│   ├── progress/        Geofence, ProgressCalculator (звания, статистика)
│   └── fog/             туман и открытые зоны
├── data/                Room (посещения, звания, активный маршрут, км), DataStore, контент из ассетов, геолокация
├── service/             RouteTrackingService — foreground-сервис, только при активном маршруте, раз в 10–20 с
├── di/                  Hilt
└── ui/                  Compose + Material 3, MVVM
content/                 контент-пак (JSON), таблица мест, пересчёт спирали, валидатор — см. content/README.md
```

Стек: Kotlin, Jetpack Compose, Material 3, Hilt, Room, DataStore, kotlinx.serialization, MapLibre Native,
Google Play Services Location. minSdk 26.

## Тесты

* `./gradlew testReleaseUnitTest` — спираль (старт в ЦАО, округа внутри МКАД первыми, кольца наружу,
  по часовой стрелке), ссылки Google Maps, закат, оптимизатор (порядок, барьеры, 11 точек),
  геофенс, звания, туман, целостность контент-пака.
* `app/src/androidTest` — UI-тесты чек-листа и выдачи звания (Compose); собираются в CI,
  запускаются на эмуляторе/телефоне: `./gradlew connectedDebugAndroidTest`.
* `python3 content/tools/validate_content.py` — схема и объёмы контента.

## Честно о том, что ещё не сделано

* **Координаты точек приблизительные.** В среде сборки нет доступа к OSM, поэтому у всех точек
  `coordsVerified: false`, а зона отметки расширена до 300 м. Нужно сверить координаты по карте.
* **Границы мест и округов** — приближённые оболочки вокруг точек маршрута (`boundarySource: "approx"`).
  Округ «закрашивается целиком», когда у него появится граница из OSM.
* **Часы работы музеев** в открытых источниках не подтверждены — расписания в контенте помечены как примерные.
* **Линия маршрута на карте — схема по порядку точек**, а не велотрасса: дорогу прокладывает Google Maps.
* **Маршруты собраны только из своих точек места.** Точка не может быть ближе к другому месту спирали,
  чем к своему (допуск 1 км), две точки разных мест не совпадают, старт и финиш — тоже в своём месте.
  Поэтому у маленьких посёлков маршрут короткий (3–5 точек), а не 40 км с заездами к соседям.
  Километраж оценён по сумме отрезков по прямой с запасом на извилистость, дорогу прокладывает навигатор.
* **Глубина рассказов разная.** Маршруты есть у всех 200 мест, но у ряда небольших посёлков
  (Андреевка, Запрудня, Большие Дворы, Шаховская и др.) история в открытых источниках не нашлась —
  в маршруте это сказано прямо, ничего не досочинено. Факты из единственного или туристического
  источника помечены `verified: false`.
* **Блюда.** У большинства мест подтверждённого местного блюда нет — там «тематическая замена» с
  пометкой, что это выбор составителя; места продажи не проверены.
