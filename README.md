# Что надеть? — погодный помощник для Android

Приложение смотрит прогноз погоды для вашего города и отвечает на главный
утренний вопрос: **во что одеться и брать ли зонт**.

## Что показывает

* **Сейчас** — температура, ощущаемая температура, ветер, порывы, влажность.
* **Совет по одежде** — конкретный список слоёв: от футболки до пуховика,
  подобранный по *самому холодному моменту ближайших 12 часов*, а не по
  текущей температуре (иначе к вечеру можно замёрзнуть).
* **Зонт** — пять вердиктов вместо «да/нет»:
  не нужен · возьмите на всякий случай · обязательно ·
  ветер сломает зонт, нужен капюшон · ожидается снег.
* **Аксессуары** — шапка, перчатки, шарф, очки, крем SPF, бутылка воды.
* **Обувь** — от сандалий до зимних ботинок, с отдельным вердиктом при гололёде.
* **Предупреждения** — сильный ветер, гроза, туман, ледяной дождь, высокий УФ,
  духота, риск обморожения.
* **Почасовой прогноз** на сутки и **прогноз на 6 дней**.

## Установка на телефон (Samsung и любой другой Android)

1. Откройте раздел [**Releases**](../../releases/tag/chto-nadet-latest) этого репозитория на телефоне.
2. Скачайте файл `chto-nadet-*.apk` из последнего релиза.
3. Откройте скачанный файл. Android спросит разрешение на установку из
   этого источника — на Samsung это
   *Настройки → Приложения → Специальный доступ → Установка неизвестных
   приложений* → выберите браузер или «Мои файлы» → **Разрешить**.
4. Нажмите «Установить».

Требуется Android 8.0 (API 26) или новее.

При первом запуске приложение попросит доступ к геолокации, чтобы показать
погоду там, где вы находитесь. Можно отказаться и выбрать город вручную —
кнопка поиска 🔍 в верхней панели. Выбранный город запоминается.

## Откуда берётся погода

Используется [Open-Meteo](https://open-meteo.com) — бесплатный API прогноза
погоды: **без регистрации, без API-ключа, без лимитов для личного
использования**. Поэтому APK работает сразу после установки, ничего
настраивать не нужно.

Яндекс.Погода намеренно не используется: её API требует ключ, привязанный к
аккаунту разработчика, и с 2024 года платный даже для небольших объёмов —
такой ключ пришлось бы зашивать в APK. Если ключ у вас всё же есть, заменить
источник просто: вся сетевая часть изолирована в
[`WeatherRepository`](app/src/main/java/com/weatherwear/assistant/data/WeatherRepository.kt),
а остальное приложение работает с моделью `WeatherBundle` и не знает, откуда
пришли данные.

Поиск города — геокодер Open-Meteo, определение своего города по координатам —
штатный `Geocoder` Android. Google Play Services не требуются.

## Как устроен код

```
app/src/main/java/com/weatherwear/assistant/
├── MainActivity.kt          — точка входа, запрос разрешений
├── WeatherViewModel.kt      — состояние экрана, загрузка, поиск города
├── data/
│   ├── Models.kt            — Place, CurrentWeather, HourlyPoint, DailyPoint
│   ├── WeatherRepository.kt — Open-Meteo: прогноз и поиск города
│   ├── LocationProvider.kt  — координаты через LocationManager
│   ├── Prefs.kt             — запоминание выбранного города
│   └── Http.kt              — минимальный HTTP-клиент
├── domain/
│   ├── ClothingAdvisor.kt   — вся логика советов (чистый Kotlin, покрыт тестами)
│   ├── AdvicePlanner.kt     — агрегация прогноза за ближайшие 12 часов
│   └── WeatherCodes.kt      — расшифровка кодов погоды WMO
└── ui/                      — экраны на Jetpack Compose (Material 3)
```

Логика советов вынесена в чистые функции без зависимостей от Android, поэтому
её можно менять под себя и проверять юнит-тестами:

```bash
./gradlew testReleaseUnitTest
```

Пороги температур легко подкрутить под свою «мерзлявость» — они собраны в
`ClothingAdvisor.bandOf()`.

## Сборка своими руками

Нужен JDK 17 и Android SDK (platform 35):

```bash
./gradlew assembleRelease
# готовый файл: app/build/outputs/apk/release/app-release.apk
```

Каждый push в ветку автоматически собирает APK через GitHub Actions
(`.github/workflows/android.yml`) и обновляет prerelease **latest**.
Тег вида `v1.2` создаёт обычный релиз с тем же APK.

### О ключе подписи

В репозитории лежит `keystore/chtonadet.jks` с пустым паролем-заглушкой
(`chtonadet`). Он нужен только для того, чтобы **все сборки имели одинаковую
подпись** и приложение обновлялось поверх старой версии без удаления.
Ключ публичный и не защищает ничего — не используйте его для публикации в
Google Play. Для приватной подписи задайте в CI секреты и переменные
окружения `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
