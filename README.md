# Tower War (Война Башен)

Пошаговая магическая стратегия захвата территорий на картах реальных городов. Первая карта — Гент, дальше в планах Антверпен, Брюссель, Стамбул и Токио. Полная спецификация лежит в [GAME_SPEC.md](GAME_SPEC.md).

Движок — Godot 4.7.2 (GDScript со статической типизацией), платформы — Android и PC. Карты строятся из данных OpenStreetMap: © OpenStreetMap contributors, лицензия ODbL.

## Структура

```
game/                    Godot-проект
  src/sim/               детерминированная симуляция, без Node и сцен
  src/data/              загрузка данных (пакеты карт, правила)
  src/view/ src/input/   рендер карты и единый слой ввода (мышь и тач)
  src/tools/             headless-инструменты (партии ИИ против ИИ)
  src/ui/                экраны
  data/rules/            общий баланс: школы, юниты, заклинания, эффекты
  data/maps/<city>/      пакеты карт (генерирует tools/geo)
  locale/                строки ru/en; locale/maps/<city>.csv — строки карт
  tests/                 GUT-тесты и фикстуры
tools/geo/               Python-пайплайн OSM → пакет карты, конфиги городов в cities/
tools/tests/             общие тесты инструментов (эталонный RNG)
tools/schematic/         временная схематичная карта Гента до запуска геопайплайна
docs/                    форматы данных
scripts/                 установка Godot и запуск всех тестов
archive/                 файлы, не относящиеся к игре
```

## Что уже играется

Прототип с базовым циклом захвата (ядро фазы 3 из спецификации, без магии):

- главное меню: выбор фракции, числа противников-ИИ и сложности, режим хотсит;
- карта Гента: 48 территорий, река и мосты, рельсовая связь вокзалов, 26 достопримечательностей и три Коронные башни;
- ходы и дни, день и ночь, доход гульденами и маной, содержание армии, лечение гарнизонов;
- перемещение и атака по графу с предпросмотром шанса победы, автобой по формуле из раздела 4.4;
- захват территорий, нейтральные гарнизоны и Хранители Башен, ритуал связывания достопримечательностей;
- найм в своих связанных достопримечательностях, туман войны;
- победа Господством, Коронными башнями или Уничтожением; простой ИИ.

**Карта пока схематичная.** OSM недоступен из среды сборки, поэтому `game/data/maps/ghent/map.json` построен скриптом `tools/schematic/ghent_schematic.py`: примерное взаимное расположение мест, ячейки Вороного, условные мосты. Это не реальная геометрия; её заменит выход геопайплайна (фаза 1), формат тот же.

Все числа баланса с пометкой [тюнинг] лежат в `game/data/rules/balance.json` (юниты, бой, экономика, захват, нейтралы, победа, ИИ). Мана и Хранители достопримечательностей Гента лежат в `game/data/maps/ghent/landmarks.json`.

Управление: ЛКМ или тап выбирает территорию, ЛКМ или тап по подсвеченной соседней задаёт приказ, «Подтвердить» выполняет. Перетаскивание двигает карту, колесо или щипок меняет масштаб. Enter завершает ход или подтверждает приказ, Space выбирает следующую армию, Esc снимает выбор.

## Запуск игры

```bash
GODOT=$(scripts/setup_godot.sh)
$GODOT --path game
```

Партии ИИ против ИИ без графики (CSV: победитель, тип победы, длительность):

```bash
$GODOT --headless --path game -s res://src/tools/headless_match.gd -- 10 ghent
```

## Запуск тестов

```bash
scripts/test.sh          # скачает Godot 4.7.2 в .tools/ при первом запуске
```

Или по отдельности:

```bash
GODOT=$(scripts/setup_godot.sh)
$GODOT --headless --path game --import
$GODOT --headless --path game -s res://addons/gut/gut_cmdln.gd
cd tools/geo && python3 -m pytest
```

## Открыть в редакторе

Откройте `game/project.godot` в Godot 4.7.x. GUT (9.7.1) уже лежит в `game/addons/gut`.

## Новый город

1. Создайте `tools/geo/cities/<city>.toml` по образцу `ghent.toml`.
2. Добавьте строки карты в `game/locale/maps/<city>.csv`.
3. Запустите пайплайн (фаза 1): см. [tools/geo/README.md](tools/geo/README.md).

В коде движка нет данных о конкретных городах: всё городское хранится в пакете карты (формат описан в [docs/map_format.md](docs/map_format.md)).
