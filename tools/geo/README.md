# tools/geo: OSM → пакет карты Tower War

Пайплайн строит пакет карты города (`game/data/maps/<city>/`) из данных OpenStreetMap. Сгенерированные файлы коммитятся в репозиторий, а сырые выгрузки кешируются в `tools/geo/.cache/` (в git не попадают).

## Окружение

```bash
cd tools/geo
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
```

Для запасного источника нужна утилита `osmium` (пакет `osmium-tool`).

## Команды

```bash
python -m towerwar_geo check-config ghent   # проверка конфига города
python -m pytest                            # тесты
```

Шаги генерации (загрузка, территории, граф, достопримечательности, тайлы, валидация) добавляются в фазе 1.

## Конфиг города

`cities/<city>.toml` содержит:
- границу (`[area]`);
- источники данных (`[source]`): сначала Overpass, запасной вариант — выгрузка Geofabrik, обрезанная `osmium` по границе;
- проекцию (`[projection]`): EPSG-код или `auto-utm`;
- параметры нарезки территорий (`[territories]`);
- Коронные башни и стартовые позиции (`[game]`);
- достопримечательности (`[[landmarks]]`) с правилами поиска в OSM.

Координаты в конфиге не пишутся никогда: каждая достопримечательность находится в OSM. Если поиск ничего не нашёл, пайплайн останавливается и выводит список ненайденных объектов.

Баланс (мана, эффекты) хранится не здесь, а в `game/data/maps/<city>/landmarks.json`.
