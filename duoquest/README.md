# DuoQuest ⚔️💜

Приложение для двоих: вы ставите друг другу задания со сроками, промежуточными
напоминаниями, наградами и наказаниями — а происходящее превращается в RPG с
персонажами и сюжетом, который пишет нейросеть.

Один код, две платформы: **Android и iPhone**.

---

## Что умеет

| Возможность | Как реализовано |
|---|---|
| Задания друг другу | Квест «Себе», «Партнёру» или «Обоим на двоих» |
| Сроки выполнения | Дедлайн с датой и временем, напоминание за час и в момент срока |
| Реперные точки | Произвольное число промежуточных напоминаний на конкретное время |
| Общие задачи | Тип «Обоим» — квест закрывается, когда отметились оба |
| Награда и наказание | Свободным текстом + игровые XP/золото/HP; долги копятся во вкладке «Долги» |
| RPG-персонажи | 5 классов, уровни, опыт, здоровье, золото, характеристики |
| Сюжет от нейросети | Главы пишет бесплатная LLM по итогам реально закрытых квестов |
| Синхронизация | Realtime между Android и iPhone через Supabase |
| Уведомления | Локальные (точки, дедлайны) + push от партнёра |

---

## Сначала — важное про iPhone

**Готовый файл для установки на айфон (`.ipa`) сделать нельзя ни здесь, ни где-либо
ещё без учётной записи Apple.** Apple требует подписи сертификатом разработчика,
и это принципиальное ограничение платформы, а не проекта.

Поэтому для айфона есть два пути:

| Путь | Стоимость | Что нужно |
|---|---|---|
| **Expo Go** (рекомендую начать с него) | бесплатно | Установить Expo Go из App Store и открыть проект — приложение запустится полноценно |
| **TestFlight / App Store** | $99/год | Аккаунт Apple Developer, сборка через `eas build --platform ios` |

Для Android никаких ограничений нет — APK собирается и ставится напрямую.

## Шаг 1. Бэкенд на Supabase (бесплатно, ~10 минут)

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) и создайте новый проект.
   Регион выбирайте ближайший, пароль к базе сохраните.
2. Откройте **SQL Editor** → **New query**, вставьте целиком содержимое файла
   [`supabase/migrations/0001_init.sql`](supabase/migrations/0001_init.sql) и нажмите **Run**.
   Это создаст таблицы, права доступа и включит realtime.
3. Откройте **Project Settings → API** и скопируйте два значения:
   - `Project URL`
   - `anon public` ключ
4. *Необязательно.* Переключатель **Confirm email** можно выключить, чтобы не
   возиться с письмами при регистрации. В разных версиях панели он лежит
   по-разному: пролистайте вниз развёрнутый блок **Authentication → Sign In /
   Providers → Email**, а если его там нет — загляните в **Authentication →
   Emails**. Не нашли — пропускайте, приложение работает и так.

   Если подтверждение осталось включённым, при регистрации придёт письмо. По
   клику на ссылку откроется пустая страница или ошибка — это нормально,
   возвращаться ссылке некуда, аккаунт уже подтверждён: вернитесь в приложение
   и войдите. Встроенный отправитель Supabase на бесплатном тарифе шлёт лишь
   несколько писем в час.

### Edge-функции (сюжет и push)

Ставится один раз с компьютера:

```bash
npm install -g supabase
supabase login
supabase link --project-ref <ref-вашего-проекта>

# Ключ бесплатной LLM — см. следующий раздел
supabase secrets set LLM_PROVIDER=groq
supabase secrets set LLM_API_KEY=<ваш-ключ>

supabase functions deploy generate-story
supabase functions deploy notify-partner
```

Без этого шага приложение полностью работает — не будет только автоматического
сюжета и пушей партнёру.

## Шаг 2. Бесплатная LLM для сюжета

Поддерживаются три провайдера, у всех есть бесплатный тариф. Достаточно любого одного:

| Провайдер | Где взять ключ | `LLM_PROVIDER` | Модель по умолчанию |
|---|---|---|---|
| **Groq** (быстрее всего) | [console.groq.com/keys](https://console.groq.com/keys) | `groq` | `llama-3.3-70b-versatile` |
| **OpenRouter** | [openrouter.ai/keys](https://openrouter.ai/keys) | `openrouter` | `meta-llama/llama-3.3-70b-instruct:free` |
| **Google Gemini** | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) | `gemini` | `gemini-2.0-flash` |

Модель можно переопределить: `supabase secrets set LLM_MODEL=<имя>`.

## Шаг 3. Получить APK для Android

### Вариант А — через GitHub Actions (ничего не надо ставить на компьютер)

1. Ничего настраивать не нужно: адрес проекта и публичный ключ лежат прямо в
   `src/lib/supabase.ts`. Публичный ключ и так извлекается из любого APK, данные
   защищают политики RLS в базе, а не его секретность.

   Собрать на **другой** проект Supabase можно, не трогая код: добавьте в
   **Settings → Secrets and variables → Actions** секреты
   `EXPO_PUBLIC_SUPABASE_URL` и `EXPO_PUBLIC_SUPABASE_ANON_KEY` — при сборке они
   имеют приоритет над значениями из кода.
2. Сборка запускается сама при каждом пуше в ветку. Вручную: вкладка **Actions**
   → workflow **«Сборка DuoQuest APK»** → **Run workflow**.
3. Через 10–15 минут свежий `duoquest.apk` окажется в релизе
   **[duoquest-latest](../../releases/tag/duoquest-latest)**. Ссылка постоянная —
   каждая сборка заменяет файл в том же релизе.
4. На телефоне откройте скачанный `.apk` и разрешите установку из этого источника.

### Вариант Б — локально

```bash
cd duoquest
cp .env.example .env      # впишите свои URL и ключ
npm install
npx expo prebuild --platform android
cd android && ./gradlew assembleRelease
# APK: android/app/build/outputs/apk/release/app-release.apk
```

## Шаг 4. Запустить на iPhone

```bash
cd duoquest
npm install
npx expo start
```

На айфоне: установите **Expo Go** из App Store, откройте камеру и наведите
на QR-код из терминала. Приложение запустится со всем функционалом; локальные
напоминания (реперные точки, дедлайны) работают.

Push-уведомления от партнёра в Expo Go не приходят — для них нужна собственная
сборка. Когда захотите полноценное приложение на айфон:

```bash
npm install -g eas-cli
eas login
eas build --platform ios --profile preview   # нужен Apple Developer аккаунт
```

## Шаг 5. Связать два телефона

1. Оба регистрируются в приложении (почта + пароль).
2. Один создаёт пару и получает **код из 6 символов**.
3. Второй вводит этот код на экране «Ваша пара».
4. Каждый создаёт своего героя — и можно раздавать квесты.

## Как устроен проект

```
duoquest/
├── app/                      экраны (файловая маршрутизация expo-router)
│   ├── (auth)/               вход и регистрация
│   ├── (tabs)/               квесты, сюжет, долги, герой
│   ├── onboarding/           создание пары и персонажа
│   └── task/                 создание и карточка квеста
├── src/
│   ├── lib/
│   │   ├── supabase.ts       клиент бэкенда
│   │   ├── notifications.ts  планирование локальных напоминаний
│   │   ├── game.ts           формулы уровней, наград и штрафов
│   │   └── dates.ts          форматирование дат по-русски
│   ├── store/                состояние (zustand): сессия и квесты
│   ├── components/           переиспользуемый интерфейс
│   └── theme.ts              палитра и константы оформления
└── supabase/
    ├── migrations/           схема БД и политики доступа
    └── functions/
        ├── generate-story/   сюжет через LLM
        └── notify-partner/   push через Expo Push Service
```

### Игровые правила

- Опыт для уровня N: `100 × (N−1)^1.6`. На новом уровне здоровье восстанавливается полностью.
- Награда зависит от сложности: от 20 XP за «Пустяк» до 400 XP за «Эпический».
- Закрыли больше чем за сутки до срока — **+25%** к награде. Закрыли после срока — награда **вдвое меньше**.
- Провал: минус здоровье и золото, серия обнуляется, наказание уходит в «Долги».

## Стоимость

Всё перечисленное укладывается в бесплатные тарифы: Supabase (база, авторизация,
realtime, edge-функции), Groq или OpenRouter (LLM), Expo Push Service (уведомления),
GitHub Actions (сборка APK). Платить придётся только за публикацию в App Store —
$99/год, и только если захотите ставить приложение на айфон без Expo Go.
