# TG Агент — личный ИИ-управляющий Telegram

Android-приложение, которое входит в ваш аккаунт Telegram (как ещё одно устройство) и выполняет команды на обычном языке:

- **Отложенные сообщения:** «напомни завтра в 9 позвонить маме», «отправь Пете в пятницу в 18:00 …», показать, перенести или удалить запланированные.
- **Сложный поиск:** «все пересланные сообщения в чате с Петей за октябрь», «ссылки, которые я сам кидал в папке Работа», «голосовые от Ани за неделю». Условия комбинируются: текст, пересланные, от кого переслано, отправитель, тип (фото/видео/документ/голосовое/ссылка), период, чат/папка/все чаты.
- **Папки:** создать, переименовать, удалить, добавить или убрать чаты, показать содержимое.

Всё, что меняет данные (отправка, отложенные, папки), приложение сначала показывает и ждёт кнопки «Выполнить».

## Как устроено

- **TDLib** — официальная библиотека Telegram, работает прямо на телефоне.
- **ИИ — DeepSeek** (`deepseek-chat`, OpenAI-совместимое API). ИИ только решает, какие действия вызвать; поиск и фильтрация идут на телефоне.
  В **приватном режиме** (включён по умолчанию) текст найденных сообщений в ИИ не отправляется — только дата, отправитель и тип. Полный список вы видите на экране.
- Адрес API и модель меняются в настройках, поэтому подойдёт любой OpenAI-совместимый сервис.

## Установка

1. Откройте на телефоне **Releases** этого репозитория → `tg-agent-latest` → скачайте `tg-agent.apk` и установите (разрешите установку из неизвестных источников).
2. Получите `api_id` и `api_hash` на https://my.telegram.org → *API development tools*.
3. Получите API-ключ DeepSeek на https://platform.deepseek.com → *API keys* (нужно пополнить баланс).
4. Запустите приложение, введите ключи в настройках, затем телефон, код из Telegram и облачный пароль (если включён).

Ключи хранятся только в приватном хранилище приложения на телефоне и не попадают в репозиторий.

## Сборка

APK собирает GitHub Actions (`.github/workflows/tg-agent.yml`): сначала TDLib из исходников (первый раз около часа, потом берётся из кэша), затем приложение. Только arm64-v8a.

## Ограничения

- Telegram разрешает около 10 папок (20 с Premium), до 100 выбранных чатов в папке и название папки до 12 символов.
- Поиск без текста листает историю чата, поэтому по большим чатам он небыстрый. Глубину ограничивает `scan_limit`.
- Не делайте массовых действий: Telegram может ограничить аккаунт за подозрительную активность неофициальных клиентов.
- `debug.keystore` в репозитории нужен, чтобы обновления ставились поверх старой версии без повторного входа.
