# Контент-пак «Велоподмосковье»

Всё, что видит пользователь, лежит здесь и упаковывается в APK как ассеты (`content/pack`).

```
content/
├── pack/                       ← уезжает в APK
│   ├── manifest.json           версия пака и список мест с готовым маршрутом
│   ├── spiral.json             все 365 мест спирали (ЦАО → округа внутри МКАД → кольца наружу), «самые-самые»
│   └── destinations/*.json     маршрут места: точки, рассказы, факты, блюдо, звание
└── tools/
    ├── places.tsv              таблица мест: 9 округов Москвы внутри МКАД + места за МКАД
    ├── build_spiral.py         пересчёт спирали из таблицы
    └── validate_content.py     проверка схемы и объёмов, запускается в CI
```

## Правила

* **Ничего не выдумывать.** У каждого факта есть `sourceUrl`. Если факт не удалось подтвердить —
  `verified: false`, и приложение показывает его с пометкой «не проверено».
* Тексты — своими словами. Цитаты только короткие (до 15 слов), одна на источник.
* Нет своего блюда — так и пишем в `honestyNote` и предлагаем тематическую замену с объяснением.
* Адрес магазина не подтверждён — `verified: false`.
* Режимные территории, работающие заводы, ЗАТО, частные посёлки и закрытые заказники в маршрут не
  включаем. Видно только снаружи — `kind: "смотреть снаружи"`.
* Единицы — только метрические.
* Маршрут — только свои точки места (`routeVersion: 3`): 3–12 точек, цель 6–8. Точка не может быть ближе
  к другому месту спирали, чем к своему (допуск 1 км, у округов Москвы — 3 км); точки разных мест не
  совпадают (ближе 600 м — ошибка); старт и финиш — своя станция или центр места. Длина не важна: если
  в посёлке три подтверждённых объекта, маршрут короткий. Сумма отрезков по прямой не больше заявленных
  километров, а заявленные километры не больше прямой × 1,55 — иначе цифра нечестная.
* Объём: вступление 3–6 абзацев; на точку рассказ 2–6 абзацев и 2–12 фактов.
* Тематическая «точка» без своего места на карте (рассказ вместо объекта) в маршрут не идёт.

## Как добавить место

1. Уточнить координаты центра в `tools/places.tsv` (по OSM), запустить `python3 content/tools/build_spiral.py` —
   расстояния, азимуты, кольца и порядок спирали пересчитаются.
2. Написать `pack/destinations/<id>.json` (id — транслит названия, как в `spiral.json`), снова запустить
   `build_spiral.py` — он привяжет маршрут к месту и обновит `manifest.json` (одно место — один маршрут).
3. `python3 content/tools/validate_content.py` — должно быть 0 ошибок.

## Правки координат из приложения

В приложении любую точку можно сдвинуть, а в маршрут — добавить свою (экран точки → «Поправить координаты»,
экран места → «Добавить свою точку»). Правки живут в телефоне; кнопка «Настройки → Мои правки точек →
Поделиться правками» отдаёт их JSON-ом. Чтобы внести их в общий контент:

```
python3 content/tools/apply_user_edits.py edits.json --dry   # посмотреть, что изменится
python3 content/tools/apply_user_edits.py edits.json         # записать координаты в pack/destinations
python3 content/tools/validate_content.py
```

Поправленные точки помечаются `coordsVerified`. Свои точки пользователя скрипт только перечисляет:
в общий контент их добавляют руками — с рассказом и фактами по правилам выше.

## Границы мест

`boundaryGeoJson` с `boundarySource: "osm"` — граница из OpenStreetMap. Пока границы не скачаны,
приложение строит приближённую оболочку вокруг точек маршрута (`boundarySource: "approx"`); она
используется только для «тумана» на карте.
