# 🧠 Мнемо — карточки и уроки для запоминания слов

Приложение в духе Quizlet + Duolingo: карточки, заучивание, тесты, игры,
интервальные повторения и полноценные уроки, которые собираются из ваших слов.
Один код для **Android (APK)** и **iPhone (веб-приложение на экране «Домой»)**.
Работает без интернета, все данные хранятся на устройстве.

## Где взять

| Платформа | Как установить |
|---|---|
| **Android** | Скачать `Mnemo.apk` из релиза **[mnemo-latest](../../releases/tag/mnemo-latest)** и открыть файл на телефоне |
| **iPhone** | Открыть **https://kartaviyukr.github.io/-/mnemo/** в **Safari** → «Поделиться» → **«На экран „Домой“»** |

APK и веб-версия собираются GitHub Actions (`.github/workflows/mnemo.yml`) при
каждом пуше в `mnemo/`. Вручную: Actions → «Мнемо — APK и веб-версия» → Run workflow.

> Почему на iPhone не «настоящее» приложение: для установки `.ipa` Apple требует
> платный аккаунт разработчика. Веб-приложение ставится бесплатно, открывается
> без браузерной обвязки и работает офлайн.

## Режимы занятий

| Режим | Что делает |
|---|---|
| 🃏 **Карточки** | Переворот, свайп «знаю / ещё учу», перемешивание, автопрокрутка с озвучкой, отмена |
| 🎓 **Заучивание** | Как Learn в Quizlet: каждое слово проходит «выбор ответа» → «письменный ответ», раунды по 7 слов |
| 🔁 **Повторение** | Интервальные повторения (SM-2, как в Anki): «Снова / Трудно / Хорошо / Легко» |
| 📝 **Тест** | Верно/неверно, выбор ответа, письменные, сопоставление; оценка в %, разбор ошибок |
| 🧩 **Подбор** | Найти пары на время, рекорды по каждому набору |
| ✍️ **Письмо** | Написать перевод; ошибки повторяются в конце, «Я был прав», подсказка по буквам |
| 🎧 **Диктант** | Слово звучит — его нужно записать; медленное воспроизведение |
| 🔤 **Собери слово** | Слово из перемешанных букв |
| ⚡ **Спринт** | 60 секунд «верно / неверно» с множителем за серию |
| 🗺️ **Уроки** | Путь из уроков по 6 слов: знакомство → выбор → пары → на слух → вставь в предложение → собери → напиши; повторение каждого раздела и итоговый экзамен, звёзды за точность |

## Языки и словари

Три отдельные вкладки — **🇬🇧 английский, 🇮🇹 итальянский, 🇺🇦 украинский** (перевод на русский).
Внутри каждого языка наборы сгруппированы по уровням **A0 → A1 → A2 → B1 → B2 → C1**;
уроки идут курсом от набора к набору. Свои наборы на любом другом языке появляются во вкладке «🌐 Другие».

Сколько слов нужно: A1 ≈ 600, A2 ≈ 1200, B1 ≈ 2500, B2 ≈ 4000, C1 ≈ 6000–8000
(пассивный запас с накоплением). Текущий объём и разбивку по уровням показывает
`node mnemo/tools/data.mjs` (он же проверяет словари в CI).

На уровнях A0–B1 у каждого слова есть пример с переводом, на B2–C1 — пример на изучаемом языке.
В итальянском существительные даны с артиклем; в украинском есть набор «ложных друзей переводчика»
и фразеологизмы.

## Ещё

- **Справочник «Как запоминать»**: 17 статей — уровни CEFR, особенности итальянского и украинского,
  кривая забывания, интервальные повторения, активное припоминание, система Лейтнера, метод ключевых
  слов, дворец памяти, чанки, двойное кодирование, перемешивание, сон и т.д.
- **Подсказки-ассоциации** к каждой карточке — появляются при ошибке.
- **Умные наборы** (по каждому языку): «Все слова», «Изученные», «Избранное ⭐», «Трудные слова 🎯».
- **Озвучка** (системный синтез речи) на языке набора, автоозвучка, скорость речи.
- **Прогресс**: серия дней 🔥, цель дня в XP, «Путь к C1» по уровням, график недели,
  карта активности, 14 достижений.
- **Проверка ответов** прощает опечатки, пропущенные артикли и знаки ударения (è → e, ї → і).
- **Свои наборы**: ручной ввод или импорт текстом/файлом (формат Quizlet, Excel,
  «слово - перевод»), экспорт, любые языки.
- **Резервная копия** в файл и восстановление — для переноса между телефонами.
- Темы: тёмная, светлая, сепия.

## Устройство

```
mnemo/
├── app/src/main/assets/www/   всё приложение (HTML/CSS/JS, без сборки)
│   ├── app.js                 логика: режимы, уроки, SRS, статистика
│   ├── data/{язык}-{уровень}.js  встроенные словари (en, it, uk × A0…C1)
│   ├── guide.js               статьи о методиках запоминания
│   ├── manifest.json, sw.js   PWA для iPhone (офлайн, иконка)
│   └── icons/
└── app/src/main/java/…/MainActivity.java   WebView + озвучка, вибрация,
                                             «Поделиться», сохранение файлов
```

Добавить слова — дописать строку `термин|перевод|пример|перевод примера` в нужный файл
`data/…` и запустить `node mnemo/tools/data.mjs --fix` (уберёт повторы и подключит новые
файлы в `index.html`). Встроенные словари не копируются в память браузера: хранятся только
прогресс и правки пользователя, поэтому новые слова появляются после обновления, а прогресс
сохраняется (id карточки — `язык:слово`).

Локальная сборка APK: `cd mnemo && gradle assembleRelease` (нужен Android SDK).
Веб-версию можно открыть просто как `app/src/main/assets/www/index.html`.

**Важно:** workflow DuoQuest (ветка `claude/cross-platform-task-quest-app-i4mzto`)
перезаписывает ветку `gh-pages` целиком. Если после его запуска веб-версия Мнемо
пропала — перезапустите workflow «Мнемо — APK и веб-версия».
